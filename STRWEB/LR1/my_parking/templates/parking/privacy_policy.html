Политика конфиденциальности

Настоящая политика описывает, какие данные используются сайтом {{ company_global.name|default:"автомобильной парковки" }} и для каких целей они необходимы.

1. Какие данные используются

При регистрации и использовании сайта могут обрабатываться следующие данные:

  • имя пользователя;
  • адрес электронной почты;
  • номер телефона;
  • дата рождения;
  • сведения об автомобилях;
  • государственные регистрационные номера;
  • сведения о начислениях и оплатах;
  • тексты и оценки отзывов;
  • содержимое пользовательской корзины.

2. Цели обработки данных

Данные используются для:

  • регистрации и авторизации пользователя;
  • ведения личного кабинета;
  • управления автомобилями клиента;
  • расчёта начислений и учёта платежей;
  • формирования корзины услуг;
  • обработки отзывов;
  • связи пользователя с сотрудниками компании;

3. Хранение и защита информации

Доступ к данным ограничивается в соответствии с ролью пользователя. Клиент, сотрудник и администратор имеют разные права доступа.

Пароли не сохраняются в открытом виде. Для их хранения используются механизмы хеширования, предоставляемые Django.

Формы, изменяющие данные, защищаются с помощью CSRF токенов.

4. Платёжные данные

Номер банковской карты, срок действия карты и код CVV используются только для проверки формы оплаты.

Эти сведения не записываются в базу данных сайта и не выводятся на других страницах.

5. Сессии и технические данные

Сайт использует сессию Django для сохранения авторизации пользователя и содержимого корзины.

В сессии корзины хранятся идентификаторы выбранных услуг и их количество. Названия и стоимость услуг загружаются из базы данных.

6. Внешние сервисы

Для отображения погоды сайт обращается к сервису OpenWeatherMap. Для отображения местоположения компании используется виджет Яндекс Карт.

При загрузке содержимого внешнего сервиса браузер пользователя устанавливает соединение с соответствующим поставщиком.

7. Права пользователя

Пользователь может обратиться к компании, чтобы уточнить, изменить или удалить предоставленные им персональные данные, если их сохранение больше не требуется для работы учётной записи.
